# Домашнее задание к уроку 1-2

**Тема:** Виды и модели операционных систем.

**Выбранная статья:** 
[Винда, Linux или macOS: какую ОС выбрать для программирования](https://skillbox.ru/media/code/vinda-linux-ili-macos-kakuyu-os-vybrat-dlya-programmirovaniya/)



**Почему я выбрал эту статью:**
Эта статья показалась мне наиболее полезной, 
потому что в ней не просто перечисляются факты,
а приводится сравнение трех самых популярных операционных систем (Windows, macOS и Linux) 
с точки зрения разработчика. Автор объясняет, какие задачи удобнее решать в каждой из них, 
и помогает понять, как выбор ОС влияет на процесс программирования. Это напрямую связано с темой нашего урока.
